
##  Objective
Use SQL inside Python to pull simple sales info (total quantity sold, total revenue), and display it using print statements and a bar chart.

##  Tools Used
- Python (sqlite3, pandas, matplotlib)
- SQLite (no extra setup needed)
- Jupyter Notebook or .py file

##  Files
- `sales_data.db`: The database with a 'sales' table
- `sales_summary.py`: Python script to connect, query, and visualize
- `sales_chart.png`: Bar chart showing revenue by product
- `README.md`: This file

##  Output
A bar chart showing revenue by product is generated and saved as `sales_chart.png`.

- Connecting Python to SQLite
- Writing SQL queries to summarize data
- Using pandas for data analysis
